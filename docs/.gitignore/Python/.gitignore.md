# .gitignore (Python)

> Профессиональный `.gitignore` для Python-проектов.
> Стратегия: **не трекать runtime, окружения, артефакты сборки и тестирования**, трекать только исходники и конфиги.

## Что исключается

| Категория                | Пути / паттерны |
|--------------------------|-----------------|
| Кеши и компиляция        | `__pycache__/`, `*.pyc`, `*.pyo`, `*.pyd`, `*.so` |
| Runtime-файлы            | `gunicorn.ctl` |
| Виртуальные окружения    | `venv/`, `.venv/`, `ENV/` |
| Сборка и дистрибутивы    | `*.egg-info/`, `dist/`, `build/`, `*.egg`, `.eggs/` |
| Тесты и покрытия         | `.pytest_cache/`, `.coverage`, `htmlcov/`, `.tox/` |
| Тайпчекеры и линтеры     | `.mypy_cache/`, `.ruff_cache/` |
| Alembic runtime          | `alembic/__pycache__/`, `alembic/versions/__pycache__/` |
| Секреты и переменные     | `.env`, `.env.*` (кроме `.env.example`) |
| IDE и ОС                 | `.idea/`, `.vscode/`, `*.swp`, `*.swo`, `*~`, `.DS_Store`, `Thumbs.db` |

## Что трекается (явные разрешения)

| Что                | Зачем |
|--------------------|-------|
| Исходники (`.py`)  | Основной код проекта |
| Конфиги-примеры    | `.env.example` — шаблон переменных окружения |
| Документация       | `README.md`, `.gitignore` и др. |

## Структурная политика

- Все runtime- и build-артефакты, окружения, временные и секретные файлы не трекаются.
- В репозитории должны быть только исходники, шаблоны конфигов и документация.
- Если нужны дополнительные исключения — добавляй их в `.gitignore` явно.

## Подключение на проекте

```bash
cp .gitignore/Python/.gitignore /path/to/your-python-project/.gitignore
cd /path/to/your-python-project
git rm -r --cached .
git add .
git commit -m "Apply Python .gitignore"
```
